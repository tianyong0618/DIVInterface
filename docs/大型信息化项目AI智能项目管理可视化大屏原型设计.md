# 大型信息化项目AI智能项目管理可视化大屏原型设计
## 设计说明
本原型基于需求文档中甲方、承建方双视角的核心诉求，采用「模块化布局+数据可视化+AI智能交互」的设计思路，适配政企大型信息化项目的管控与执行场景，兼顾数据展示的完整性、AI能力的显性化、操作的便捷性。

## 通用设计规范
1. **视觉风格**：政企级专业风格，主色调甲方页采用「政务蓝+警示红+中性灰」，承建方页采用「科技蓝+活力橙+中性灰」；
2. **分辨率适配**：支持1920*1080（主流大屏）、2560*1440（超高清大屏）自适应；
3. **交互逻辑**：
   - 核心数据实时刷新（默认5分钟/次，支持手动刷新）；
   - AI预警模块触发时弹窗提醒+红色闪烁标注；
   - 钻取式查看：点击汇总数据可下钻至明细层（如点击“工期偏差”查看具体滞后工序）；
   - 一键导出：核心报表/报告支持PDF/Excel格式导出。

### 整体布局（6大模块，栅格化分布）

| 模块位置 | 模块名称 | 核心设计元素 & 交互 |

| 顶部通栏（1行，占比100%宽度） | 顶部标题栏 | - 左侧：项目名称（加粗大号字体）+ 项目编号（灰色小字）<br>- 中间：建设周期（起止日期）+ 当前阶段（标签化展示，如“集成调试阶段”）<br>- 右侧：AI智能综合评级（大尺寸色块：优秀-绿/正常-蓝/预警-黄/滞后-红）+ 实时更新时间（如“2024-05-20 15:30:22”）<br>- 交互：点击评级可查看AI评级依据明细 |
| 左侧上半区（2行，占比40%宽度） | AI核心智能研判区 | - 卡片1：进度达成率（环形图，如85%）+ 工期偏差（数字+箭头，如+3天）<br>- 卡片2：AI智能结论（滚动文本框，如“项目整体进度滞后3天，主要因硬件到货延迟导致集成调试工序卡点”）<br>- 卡片3：风险预警弹窗（悬浮式，红色角标提示数量，点击展开“资金拨付滞后/工期卡点”等风险项，标注风险等级+责任单位）<br>- 卡片4：督办事项AI清单（表格，列：事项名称/责任单位/最晚办结时限/整改状态）<br>- 交互：风险项点击可跳转至问题台账，督办事项支持“标记已完成” |
| 右侧上半区（2行，占比60%宽度） | 全维度进度可视化板块 | - 核心图表1：总体项目甘特总图（横向时间轴，区分一期/二期/软硬件部署等阶段，不同颜色标注计划/实际进度）<br>- 核心图表2：里程碑节点完成看板（漏斗图/柱状图，列：已完成/进行中/即将到期/逾期，标注数量占比）<br>- 核心图表3：分项工程进度占比（饼图，区分硬件采购/软件开发/系统集成等维度）<br>- 交互：甘特图可拖拽缩放时间范围，节点看板点击逾期项可查看具体节点详情 |
| 左侧下半区（2行，占比40%宽度） | 投资与资金管控板块 | - 卡片1：资金总览（数字卡片，总投资/已拨付/待拨付/预算剩余占比）<br>- 卡片2：资金使用AI分析（折线图，对比计划vs实际资金拨付节奏，超支项标红）<br>- 卡片3：合同款项节点执行进度（进度条，按合同付款节点展示完成率）<br>- 交互：点击超支项可查看AI分析报告（如“硬件采购超支10%，因市场价格波动导致”） |
| 右侧下半区（2行，占比30%宽度） | 资源与人员履约看板 | - 卡片1：驻场人员在岗数量（数字+对比值，如“25人/应到30人”）+ 岗位配置达标率（环形图）<br>- 卡片2：核心技术人员考勤（表格，列：姓名/岗位/本月在岗天数/异动提醒）<br>- 卡片3：设备到货验收台账（列表，列：设备名称/到货时间/验收状态/备注）<br>- 交互：异动提醒点击可查看人员离岗详情，设备台账支持筛选“未验收”项 |
| 底部通栏（1行，占比100%宽度） | 问题闭环&协同督办板块 | - 核心组件1：问题台账分类（标签页，区分技术问题/协调问题/需求变更）<br>- 核心组件2：问题全流程可视化（流程图，展示上报→派单→整改→复核的节点转化率）<br>- 核心组件3：需求变更AI评估（卡片，标注变更影响工期/预算的预判值，如“需求变更预计增加工期5天，增加预算8万元”）<br>- 交互：问题台账支持按状态筛选，需求变更评估可一键生成评估报告 |

### 核心AI能力交互落地
1. 进度核验：页面右上角“AI核验”按钮，点击后自动读取项目知识库，对比合同工期生成核验报告；
2. 自动预警：超期/超预算/人员缺位数据自动标红，触发悬浮预警提示；
3. 一键导出：底部“导出报告”按钮，支持导出AI项目督查报告、月度考核报表（多选格式）。

### 核心AI能力交互落地
1. 智能排程：页面左上角“AI排程”按钮，点击后自动拆解总工期，生成每日施工任务并下发；
2. 数据汇总：“生成施工简报”按钮，自动汇总现场数据生成日报/周报；
3. 卡点预判：施工进度数据异常时，自动推送卡点预判及最优解决思路（悬浮提示）；
4. 知识库对接：页面右侧“知识库”入口，输入关键词可快速调取图纸/方案/规范资料；
5. 验收资料整理：“AI整理资料”按钮，自动梳理验收材料清单并标注完成状态。

## 原型交付建议
1. 工具选型：优先使用Figma（可交付交互原型）、墨刀（快速生成高保真原型）、Axure（复杂交互逻辑）；
2. 交付物清单：
   - 甲方/承建方大屏布局图（含尺寸标注、模块占比）；
   - 核心组件设计稿（图表样式、弹窗样式、按钮样式）；
   - 交互说明文档（标注所有可点击/可操作元素的行为逻辑）；
   - 数据模拟样例（填充测试数据的原型截图，便于理解数据展示效果）；
3. 适配优化：考虑大屏触控操作（按钮尺寸≥48px）、远距离可视性（字体≥14px，核心数据字体≥24px）。
