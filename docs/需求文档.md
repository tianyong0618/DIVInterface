# 大型信息化项目AI智能项目管理可视化大屏
## 整体定位
依托**行业大模型+RAG项目知识库**，自动抓取施工日志、周报、合同、工期、人员、资金、问题台账，AI智能研判进度偏差、风险预警、资源缺口，分别产出**甲方管控总览页**、**承建方执行管控页**两大可视化页面，适配政企大型信息化建设项目。

---

# 页面一：【甲方视角 · AI项目全局管控驾驶舱】
## 页面核心作用
甲方业主方：**总控进度、盯投资、控风险、审节点、督履约、AI自动督查**
### 页面分区布局（6大模块）
1. **顶部标题栏**
项目名称、项目编号、建设周期、当前阶段、AI智能综合评级（优秀/正常/预警/滞后）、实时更新时间

2. **AI核心智能研判区（核心板块）**
- AI自动汇总：整体进度达成率、计划vs实际工期偏差天数
- AI智能结论：自动生成项目当前运行总结、滞后原因定性
- 风险智能预警弹窗：资金拨付滞后、工期卡点、设备到货延迟、资料缺失、合规隐患
- 督办事项AI清单：自动抓取未完成整改项，标注责任单位+最晚办结时限

3. **全维度进度可视化板块**
- 总体项目甘特总图（一期/二期/软硬件部署/集成调试/验收交付）
- 里程碑节点完成看板：已完成/进行中/即将到期/逾期节点
- 分项工程进度占比：硬件采购、软件开发、系统集成、培训运维、验收备案

4. **投资与资金管控板块**
- 总投资、已拨付资金、待拨付资金、预算剩余占比
- 资金使用AI分析：超支预警、拨付节奏合理性研判
- 合同款项节点执行进度

5. **资源与人员履约看板**
- 承建方驻场人员在岗数量、岗位配置达标率
- 核心技术人员在岗考勤、离岗异动AI提醒
- 设备进场、软硬件到货验收进度台账

6. **问题闭环&协同督办板块**
- 甲乙双方沟通问题台账（AI自动分类：技术问题/协调问题/需求变更）
- 问题上报-派单-整改-复核全流程可视化
- 需求变更AI智能评估：变更影响工期、影响预算预判

### 甲方页面核心AI能力
1. 自动读取项目知识库文档，对比招标文件、合同工期自动核验进度
2. 无需人工填报，抓取各方日报周报自动生成进度结论
3. 超期、超预算、人员缺位自动红色预警
4. 一键导出AI项目督查报告、月度考核报表

# 页面二：【承建方视角 · AI项目落地执行作战大屏】
## 页面核心作用
承建方总包/集成商：**抓执行、排工期、管班组、控成本、消隐患、保交付**
### 页面分区布局（6大模块）
1. **顶部作战指挥栏**
项目名称、甲方单位、当前实施阶段、距离整体竣工剩余天数、内部考核得分

2. **AI智能排程与进度调度中心**
- 整体施工实时完成率、各子系统建设进度
- AI智能工期优化建议：滞后工序抢工方案、并行施工建议
- 周/月施工计划自动拆解、任务自动下发到人

3. **分项业务实施管控区**
- 软件研发进度：模块开发、接口联调、BUG修复、版本迭代
- 硬件实施进度：点位施工、设备部署、网络调试、环境搭建
- 系统集成联调进度、第三方对接进度可视化

4. **内部成本与物资管控板块**
- 项目实际投入成本、人力成本、物料成本统计
- 物料入库、领用、剩余库存台账
- 耗材短缺、设备缺料AI提前预警

5. **人员班组与任务看板**
- 项目组组织架构可视化：项目经理/研发/实施/运维/测试
- 个人任务完成率、每日工作量AI统计
- 加班调配、人力缺口智能测算

6. **现场问题&风险化解专区**
- 现场施工障碍、技术难点、甲方需求疑问统一汇总
- AI自动匹配历史同类项目解决方案
- 待协调事项清单、需甲方配合事项一键推送同步
- 验收资料筹备进度、竣工资料AI自动整理提醒

### 承建方页面核心AI能力
1. 对内自动拆解总工期，智能排布每日施工任务
2. 自动汇总现场实施数据，生成内部施工简报
3. 提前预判施工卡点，自动推送最优解决思路
4. 对接项目文档知识库，快速调取方案、图纸、规范资料
5. 自动梳理验收材料，大幅缩短竣工整理周期

# 两大页面差异化核心区别
| 维度 | 甲方AI管控大屏 | 承建方AI作战大屏 |
| ---- | ---- | ---- |
| 核心目标 | 控合规、控投资、控工期、监督履约 | 抓落地、保进度、控成本、高效交付 |
| 数据侧重 | 合同、预算、节点、履约、风险、督办 | 施工、研发、人力、物料、内部任务 |
| AI功能偏向 | 督查核验、偏差判定、风险预警、考核评价 | 智能排程、任务拆解、难题匹配、资源调度 |
| 使用人群 | 项目业主、监理、分管领导、审计 | 总包项目经理、实施负责人、项目管理层 |
| 输出成果 | 督查报告、考核报表、拨付依据 | 施工计划、排班表、整改方案、竣工资料 |
